# Tarai Gold — Booster Product Spec Page

This repo hosts the product specification page for **Tarai Gold Booster**
(Sargassum Tenerrimum 10% Liquid Biostimulant), served via GitHub Pages
and linked from a QR code printed on the product packaging.

## Structure
- `index.html` — responsive page that displays the spec image with a download button
- `assets/booster-spec.jpg` — original full-quality spec image

## How this stays live permanently
GitHub Pages serves static files directly from this repo with no expiry —
as long as the repository exists and Pages is enabled, the URL stays active.
There is no subscription, trial, or link-shortener involved (which is what
usually causes "QR code expired" problems).
